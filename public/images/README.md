# Roadmap media directories

Use these folders for real project media when it becomes available:

- `maps/` — Creek and other map screenshots / snapshots
- `fish/` — custom species renders and in-game captures
- `wild/` — Wild Mode concepts or implemented system captures
- `updates/` — devlog images
- `ui/` — project-owned interface assets

The baseline intentionally uses CSS atmosphere and placeholders instead of fake screenshots.
